QUICK GUIDE

From MSA to an ensemble

01

Prepare a target

Upload an A3M alignment; its first record is the query sequence. Optionally provide FASTA and an initial PDB. Without an initial structure, trFlow runs initialization automatically.

02

Choose the ensemble size

Other parameters use deployment defaults. Advanced options include models, geometry exploration, and sampling steps. Multiple targets run sequentially.

03

Follow progress

Open a target to see its stage, generated structures, and logs. The local queue continues running after this page closes.

04

Explore the results

Structures are aligned by Cα atoms. Overlay the ensemble, inspect cluster representatives, or play structures in sequence. Changing cluster count updates representatives, populations, and the projection.

All computation stays local
